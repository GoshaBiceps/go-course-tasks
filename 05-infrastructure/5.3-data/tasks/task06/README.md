# Token Service — Data Layer

Учебная реализация data-слоя Token Service на Go.

## Стек

- Go
- PostgreSQL
- pgxpool
- sqlc

## Схема базы данных

### users

Хранит пользователей.

Поля:

- `id` — идентификатор пользователя
- `email` — уникальный email
- `password_hash` — хэш пароля
- `created_at` — время создания пользователя

### refresh_tokens

Хранит refresh-токены пользователей.

Поля:

- `id` — идентификатор токена
- `user_id` — ссылка на `users.id`
- `token_hash` — уникальный хэш токена
- `expires_at` — время окончания действия токена
- `revoked_at` — время отзыва токена, `NULL` для активного токена
- `created_at` — время создания токена

При удалении пользователя его refresh-токены удаляются через `ON DELETE CASCADE`.

## Репозитории

### UserRepository

Поддерживает:

- создание пользователя
- получение пользователя по email

### TokenRepository

Поддерживает:

- создание refresh-токена
- получение активного токена
- отзыв токена

Активным считается токен, который:

- не отозван
- ещё не истёк

## Транзакция

Сценарий регистрации пользователя выполняется в одной PostgreSQL-транзакции:

1. создаётся пользователь;
2. создаётся refresh-токен, связанный с пользователем;
3. выполняется `COMMIT`.

Если создание пользователя или токена завершается ошибкой, выполняется `ROLLBACK`.
